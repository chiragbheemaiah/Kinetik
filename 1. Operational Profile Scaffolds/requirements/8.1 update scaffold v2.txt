6. Implementation Notes for Developer
* Treat JSON as a prompt schema, not just an outline.
* Each node should support fields like:
o title
o purpose
o output_type (enum)
o word_count_guidance (optional)
o item_count_target (optional)
o table_schema (if output_type includes table)
o diagram_schema (if output_type includes diagram/org_chart)
o prompt_text (LLM instruction)
* Ensure downstream code consuming JSON can handle mixed output types.
